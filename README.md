# UCC Campus Advertising Platform

A proposed campus classifieds service for University of Cape Coast medical students and local businesses. Independent of MedNexus.

**Status: Phase 1 planning complete; awaiting owner approval before Phase 2.** No application, database, authentication, hosting, or external services have been implemented or provisioned.

- [Project blueprint](docs/PROJECT_BLUEPRINT.md): scope, architecture, data model, moderation, APIs, security, UX and acceptance criteria.
- [Decisions requiring review](docs/DECISIONS.md): proposed defaults and unresolved owner decisions.
- [Delivery plan](docs/DELIVERY_PLAN.md): small branches/PRs, verification and deployment preparation.

This local repository uses `docs/phase-1-blueprint` for planning. A GitHub remote has not been supplied; no remote branch or PR exists yet. Product name and hosting address remain provisional.
